# 🐝 Beecrowd Resoluções

Repositório dedicado ao armazenamento das minhas resoluções de problemas na plataforma [Beecrowd](https://judge.beecrowd.com/pt). O objetivo principal deste espaço é o treinamento contínuo de lógica de programação, estruturas de dados e algoritmos complexos.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagens:** Python 3.9 🐍
* **Editor:** VS Code

---

## 📂 Estrutura do Repositório

Os problemas estão organizados em pastas que seguem as categorias oficiais da plataforma. Os arquivos individuais utilizam o padrão de nomenclatura `ID_Nome_do_Problema.py`. Além disso, dentro de cada categoria existem tabelas de progresso para facilitar a navegação.

---

## 📚 Categorias

Clique em uma categoria para ver a tabela de progresso e as soluções dos problemas:

* 🟢 [Iniciante](./Iniciante/) - Conceitos básicos de entrada, saída e lógica condicional/repetição.


Atualizado conforme novas categorias surgem.
